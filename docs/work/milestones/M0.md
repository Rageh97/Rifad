[B003P](../batches/B003P.md), [B004](../batches/B004.md) and [B004b](../batches/B004b.md) complete only their listed children (planning/governance, kernel, request context, API errors, logging, data classification). No persistence, RLS, sync, fiscal or provider guarantee is verified by these batches.

ADR-044 (2026-11-03) moves the Edge parts of this gate (Edge operational API, prototype, Cloud-to-Edge commands, lifecycle, resilience drill) to the full-operations phase F1 of the [roadmap](../roadmap.md). The gate content is unchanged; only its timing moves.
