## Implementation choices

`docs/work/governance.json` lists approved instruction scopes and each batch's approved task IDs in execution order. The checker validates every batch file against it: known IDs only, ordered dependencies (same or earlier batch), allowed task states, COMPLETE batches have only COMPLETE tasks, and an explicit user approval line. B001's original frozen scope is preserved as manifest data. `tools/run-unit-tests.mjs` discovers every `*.spec.ts` under apps/ and libs/ and fails when none exist.
