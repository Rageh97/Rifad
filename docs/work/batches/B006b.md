## Behavior

- `initTracing` sets a global W3C trace-context propagator, async-local context manager and tracer provider (`service.name = rifad-<runtime>`). With `RIFAD_OTEL_EXPORTER_URL` (http/https loopback, explicit port, no credentials) spans are batched to that OTLP/HTTP endpoint; without it spans and IDs exist but nothing leaves the process. All three roots initialize it before the HTTP app and shut it down on stop.
- HTTP: one SERVER span per request (`HTTP <method>`, method, path without query string, request ID, status; ERROR status for 5xx). A valid caller `traceparent` continues its trace; malformed values are ignored.
- Logs: every line written inside a span gains `traceId` and `spanId` next to `requestId`/`correlationId`.
- Database: one CLIENT span per query from Kysely's measured duration with only `db.system.name` and the operation keyword; SQL text and parameters are never recorded.
- Outbox: migration `0005_events_outbox_trace` adds a validated `trace_parent` column; `appendToOutbox` stores the writer's traceparent; the relay's PRODUCER `outbox publish` span continues that trace, so API request → DB write → worker publish form one trace. The event envelope contract is unchanged.

## Risk review

Assets: telemetry content and egress. Controls: no exporter by default; loopback-only endpoint validated without echoing values; spans carry no SQL, parameters, query strings, payloads or error messages (error names/codes only); caller trace headers are format-checked. Residual: a real collector/backend, sampling and retention are G16/G02 decisions; Edge exporting off-device is not allowed by configuration. Performance: one span per request and per query with batched export; not measured.

## Implementation choices

OpenTelemetry SDK 2.12.0 family (2026-10-06), OTLP/HTTP exporter 0.223.0 (same release train) and API 1.9.1: the newest set at least two weeks old; 3.0.0/0.300.0 were inside the two-week rule. Manual spans instead of auto-instrumentation keep the dependency set small and the recorded attributes explicit. The traceparent is outbox transport metadata, not an envelope field, so the shared Edge/Cloud contract does not change.
