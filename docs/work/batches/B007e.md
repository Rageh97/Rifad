## Behavior

- `openEdgeStore` (`@rifad/edge-store`, `runtime:edge`): `better-sqlite3-multiple-ciphers` 12.11.1 with SQLCipher. The 32-byte hex key is mandatory outside `test`, and a wrong key fails with `EDGE_STORE_UNREADABLE` before any use. The store runs in WAL mode with `synchronous = FULL`, foreign keys and a 5 s busy timeout. It is bound to one tenant and branch identity.
- Edge migrations follow the Cloud migrator's rules: checksums, in-order application in one immediate transaction, and refusal of edited or removed migrations.
- `local_outbox` table:
  - Uses the same `EventEnvelope` contract as the Cloud outbox, and accepts only EDGE and EDGE_TO_CLOUD planes (ADR-041).
  - Unique per tenant idempotency key and per aggregate version.
  - Has a monotonic `sequence`, used as the inbox `sourceSequence`.
- `appendLocalEvent` is called inside the same `db.transaction` as the branch state change, so state and event commit atomically offline. It rejects events for another tenant or branch (`EDGE_SCOPE_VIOLATION`).
- Read/acknowledge helpers:
  - `pendingLocalDispatch` / `markLocallyDispatched` serve the local dispatcher (M0-033).
  - `pendingCloudSync` / `markSyncedThrough` serve Edge Sync toward the Cloud inbox (M0-022).
- Version choice: 13.0.3 compiles from source on every install (needs Python and a C++ toolchain, absent on this machine), while 12.11.1 declares Node 20–26 support and installs a prebuilt binary from the package's GitHub releases through `prebuild-install`, compiling only as a fallback. pnpm allows its install script (`allowBuilds`), as accepted with E02; the prebuilt Windows x64 binary installed on 2026-11-02.

## Risk review

Abuse cases: a device or file stolen (SQLCipher encryption; key required), wrong or tampered key (fails closed), events for another tenant or branch (scope check), Cloud-plane events written locally (rejected), duplicate or replayed events (unique constraints), torn writes on power loss (WAL plus full sync). Residual: key custody, rotation, recovery and device replacement are G08; the native module needs a prebuilt or compiled binary for each Edge platform; the dispatcher and sync transport are not built yet.
