## Behavior

- `currentCorrelationId()` (`@rifad/request-context`) gives code that creates an event envelope the active request's correlation ID, or a fresh one outside a request.
- `eventContext(envelope)` builds the worker's execution context from the event: its correlation ID, organization and branch, with a fresh request ID. `startEventConsumer` runs every delivery inside that context and inside the active CONSUMER span, so handler logs carry the originating `correlationId` plus `traceId`/`spanId` (B006b).
- Tenant fields come from the envelope of an RLS-checked outbox row, never from a caller; envelopes are validated before use.

With B004 (API request context), B004b (logs), B005/B006 (outbox and relay) and B006b (traces), one correlation ID now spans API request → outbox row → queue job → consumer logs.
