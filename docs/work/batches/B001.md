## Risk review

Assets: source/instructions, local configuration, process integrity. Actors: developer and local client. Entry points: environment, local liveness HTTP, DOCX extraction and CI inputs. Controls: loopback binding, local/test-only configuration, value-free failures, source identity validation, pinned tools, negative boundary fixtures, unprivileged secret-free CI. Remaining risk: local liveness is unauthenticated and deliberately contains no business data; production isolation, authorization and persistence are not implemented. Performance: bounded startup/shutdown only; no product SLO claim.

## Implementation choices

Use Node 24 LTS, Nest 11.2.x/Fastify, Nx/pnpm and TypeScript per baseline. Node built-in test runner plus tsx avoids a larger test framework. Configuration is a small pure library; three tiny composition roots remain explicit. Rectangular source tables render as Markdown tables; extraction fails on unsupported structures. No governance framework or exceptions.
