## Acceptance

Codex edits only in a disposable detached Builder worktree. The orchestrator independently checks every changed path, runs deterministic gates, creates candidate commits, pushes, opens PRs and evaluates exact-SHA CI. Antigravity verifies independently in a separate detached worktree at the candidate SHA. Its environment is explicitly allowlisted; snapshots before and after cover HEAD, tree, index, diff, tracked content, status and refs. Any mutation is a protocol violation. The verifier worktree is removed after evidence is recorded. No agent controls GitHub, no automatic merge, and no debate protocol in V1.

Preflight validates repository-pinned Node 24.21.0 and pnpm 11.19.0, installed CLI capabilities/authentication, B001 dependency evidence, protected main and both required GitHub Actions checks. Unsupported CLI or unsafe Windows isolation blocks execution. TaskSpecs define exact allowed paths and risk. LOW uses deterministic gates and CI; STANDARD adds independent verification; CRITICAL adds a fresh final verifier context. Soft token budgets require a progress review before another expensive invocation; hard limits stop the run. At most two verifier-fix and two CI-fix rounds are allowed.

## Exclusions

No restaurant-domain implementation, business data/schema, persistence, sync, providers, real production credentials, production infrastructure or Product Batch. No auto-merge or multi-agent debate.

## Security and recovery

Assets are source, credentials, Git refs and CI evidence. Entry points are TaskSpecs and CLI output. Controls include strict schema validation, path validation, sanitized agent environments, process timeouts/output limits, detached worktrees, pre/post integrity snapshots, SHA binding, independent scope enforcement, protected main and exact-SHA CI. Agent output is untrusted. A failed or over-budget run stops in a terminal state with local evidence; a pushed PR remains for human review. The pipeline never changes main directly. Windows sandbox limitations must be measured in the live isolation check and reported honestly.
