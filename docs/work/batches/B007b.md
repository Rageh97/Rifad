## Behavior

- **Identity** (`identity-contract`, `identity-infrastructure`): `oidcTokenVerifier` checks signature (remote JWKS, https or loopback), issuer, audience, expiry and asymmetric algorithms with `jose` 6.2.12; any failure is `UNAUTHENTICATED` without echoing the token. `authenticate` resolves (issuer, subject) through `identity.external_identity` (migration 0008, platform-level, runtime role read-only) to a platform user ID or fails `IDENTITY_NOT_PROVISIONED`. No vendor SDK (G12 vendor and MFA still open).
- **Authorization** (`authorization-*`, migration 0009 in schema `authorization_ctx`): permissions `<area>.<action>` from a known list (including `checks.create/read/submit_round`); roles per organization with unique names; assignments link a membership to a role for the whole organization or one ACTIVE branch (verified through the Organizations directory, never its tables). `isAllowed` denies unknown permissions, other tenants' roles, branch assignments for organization-level actions, and anything missing. Revoking deletes the assignment.
- **Entitlements** (`entitlements-*`, migration 0010): per-organization module switches; `platform.core` is always on, every other module is off until enabled. `featureForPermission` maps permission areas to modules (`checks.*` → `restaurant.ordering`).
- All tenant tables have forced RLS from their creating migration; `db:migrate` runs migrations 0001–0010 in order.

## Risk review

Abuse cases: forged or expired tokens (JWKS signature, issuer/audience/expiry; generic failure), algorithm confusion (asymmetric allowlist), unprovisioned subjects (explicit failure), privilege escalation through unknown permissions (rejected on role definition and evaluation), cross-tenant roles or assignments (RLS plus organization checks), branch-scope bypass (branch assignments never satisfy organization-level actions), disabled module accessed via a broad role (entitlement checked separately; applied in the B007c pipeline). Residual: no token revocation list or session store yet; role/assignment changes are not yet audited (B007c); JWKS reachability affects login availability.
